## Fork integration

- **Discord** keeps the existing page ID, server order, dimming, call layout, icons and immediate mute/deafen badge. The agent combines upstream speaking state with the authenticated member ID and server-enforced mute/deafen flags. The custom page keeps its original polling cadence.
- **Discord Official** is a separate 12 × 6 widget with its own favorites. The one-time agent upgrade places it after the existing custom Discord page and copies its control permission. Phones restricted to a page list gain access only if their list included the custom page. Removing the comparison page later persists. Read-only chat and screen sharing require their own opt-ins and Discord authorization on the live agent.
- **AI quotas** use the upstream quota readers and cache. Migrating an A52 layout that uses bars also enables live Codex quota polling. The pace tick, percentage used, warning colors and reset line retain their A52 design. Quota labels use the upstream localization. A later opt-out persists.
- **VALORANT** keeps the original agent host, widget, styles, phone routes, Android map-image permission, key-down/up handling, and phone connect/disconnect hooks. The shared Windows telemetry collector receives the upstream CPU-temperature fix.
- **Build scope** keeps the Windows-only agent, original Android package ID and A52 signing identity. The release-tooling, translations of the README, and Unix source previously removed from this fork stay excluded. The 0.9.29 app uses Android version code 50.
- **Upgrade behavior** uses the agent's version-checked configuration save and ordinary backup. Existing automatic-update preferences carry over. Use a matched A52 agent and APK for deployment. The stock updater can replace the custom agent.

## Verification

- Android debug build and self-contained Windows x64 publish succeeded. All 37 panel files in the staged APK matched the build sources. Both the old and new debug APKs passed signature verification and shared one certificate.
- Seventeen agent regression checks passed against a temporary profile. Coverage includes original page options and order, per-phone page selection, persistence of later edits, live quota opt-out, the VALORANT phone routes and Discord member identity. Run `dotnet run --project checks/A52Compatibility -c Release`.
- In desktop Chrome, the custom mute/deafen buttons and the signed-in member badge updated and cleared together. The official page displayed speaking rings, switched input mode, and opened chat. The AI page rendered horizontal bars and pace markers.
- The VALORANT preview displayed the party count and timer. Touch swipes over Mic, Save clip and Hold to talk scrolled without sending a shortcut action. A stationary hold sent the down, renewal and release requests. The VALORANT widget, host and endpoint implementations matched the deployed source, as did the custom CSS for all three features.
- Real A52 touch input, Android shared-mouse input, Discord permissions, live quota retrieval, and in-game VALORANT/Medal behavior are pending device verification for this candidate.
